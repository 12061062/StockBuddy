DevOps First Way (Flow)
- The First Way of DevOps focuses on improving the flow of code from development to delivery. In our project, this was implemented during Sprint 6 by introducing continuous integration and streamlining our workflow. We ensured that code changes moved quickly through development and testing with minimal delays.

Key implementations:
- Integrated GitHub Actions to automatically run tests on code changes
- Added automated testing scripts to reduce manual testing
- Improved workflow so code is tested immediately after commits
- Reduced steps required to run and test the application

DevOps Second Way (Feedback)
- The Second Way of DevOps focuses on fast feedback loops so developers can quickly identify and fix issues. In our project, this was implemented during Sprint 7 by improving test visibility, notifications, and bug resolution processes.

Key implementations:
- Improved test result output for better readability
- Implemented notifications for failed builds/tests
- Enhanced test cases based on previous failures
- Identified and resolved recurring system bugs
