Change Management
==================================================================
1. Proposed changes were added to the product backlog.
2. During Sprint Planning, the team reviewed and prioritized backlog items.
3. Selected items were assigned to team members for implementation during the sprint.
4. Completed features were reviewed during the Sprint Review before being accepted as finished work.

Example Issues Encountered
- Some bugs that were identified and resolved during development include: 
1. Incorrect tax calculations when items were added or removed from the cart.
2. Duplicate SKU values being accepted in the inventory database.
3. Inventory stock levels not updating correctly during rapid checkout actions.
- These issues were resolved through improved validation logic, transaction handling, and additional testing.

==================================================================

Bug Tracking Process
==================================================================
To manage changes and track issues throughout development, the team followed a structured change management and bug tracking process using Jira and GitHub.

Bug Identification
Bugs were typically identified through: 
- Unit testing
- Manual testing during sprint development
- Peer code reviews
- Observations during checkout or inventory operations

Bug Resolution Process
1. A developer was assigned to investigate the issue.
2. The developer reproduced the bug and identified the root cause.
3. A fix was implemented in a separate development branch.
4. The fix was tested locally and verified through manual testing or unit tests.
5. The updated code was committed and merged into the main branch.
