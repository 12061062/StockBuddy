StockBuddy is designed as a desktop point-of-sale and inventory management system for small businesses. The application uses a Windows Forms front end to provide screens for checkout, product management, inventory viewing, and receipt handling. Users can scan barcodes, manage products, complete transactions, and track stock levels through a single desktop application.

The system follows a layered architecture. In this design, the application is separated into different layers with specific responsibilities. The presentation layer consists of the Windows Forms user interface, which handles user input and screen navigation. The business logic layer contains the core application rules, such as calculating totals, processing transactions, validating input, and updating inventory. The data layer manages communication with the SQLite database, including inserting, updating, deleting, and retrieving records.

This layered approach was chosen because it keeps the system organized and easier to maintain. It separates the user interface from the underlying logic and database operations, which improves readability, simplifies testing, and makes future changes easier to implement. SQLite is used as the persistence layer because it is lightweight, file-based, and well suited for a single-machine deployment. Overall, the architecture emphasizes simplicity, modularity, and maintainability for a small-scale retail application.
